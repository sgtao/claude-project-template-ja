# KICKOFF.md — 最初のプロンプト（{{PROJECT_NAME}}）

資料を `01_sources/` に置いてから、Claude Code を開き、下の枠の中を最初のメッセージとして渡す。
モデルは Opus を勧める（依頼書づくりのため）。

```text
BRIEF.md を、本文を書く前に完成させてください。本文はまだ書きません。

依頼：{{GOAL}}
読み手：{{READER}}
成果物：{{DELIVERABLE}}
仕事の型：{{WORK_TYPE_LABEL}}

やること：
1. 01_sources/ の資料を一覧し、関係しそうなものは、依頼に書かれていないものも開く
2. BRIEF.md の [要記入] をすべて埋める
   - 対象の単位（条項、論文、選択肢など）を数え、01_sources/units.txt に 1 行に 1 つ書く
   - 合格条件は、数えられる形で 10 個以内
   - 審査の役割を、仕事の型に合わせて決める（抽出＝相手方や査読者、生成＝想定読者、
     統合＝方法論の専門家、判断＝反対役）
   - 足りない資料を挙げる。仮の前提で進められるものは、前提を書く
3. python3 _tools/check_spec.py BRIEF.md を実行し、不合格を直す
4. 仮の前提では進められない点だけ、最後にまとめて質問する
5. BRIEF.md の要点を 10 行以内で報告し、確認を待つ
```

BRIEF.md を確認したら、次からは `/milestone` で進める（最初は、対象 1 件だけを最終の形まで仕上げる）。
