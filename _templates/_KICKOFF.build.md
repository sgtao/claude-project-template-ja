# KICKOFF.md — 最初のプロンプト（{{PROJECT_NAME}}）

Claude Code を開き、下の枠の中を最初のメッセージとして渡す。モデルは Opus を勧める（仕様づくりのため）。

```text
SPEC.md を、実装の前に完成させてください。コードはまだ書きません。

依頼：{{GOAL}}
完成物：{{DELIVERABLE}}
使いたい技術：{{STACK}}

やること：
1. SPEC.md の [要記入] をすべて埋める
   - 合格条件は、スクリプトか画像で確かめられる形で 10 個以内。形容詞は数値に直す
   - 技術は、この環境で動くことを最小のコードで実際に確かめてから書く
   - マイルストーンの最初は「粗くても最終の出力まで通る版」。以降は各 1〜2 時間の規模
   - リスクを大きい順に 3 つと、その回避策
2. python3 _tools/check_spec.py SPEC.md を実行し、不合格を直す
3. 迷う点は、仮の前提を置いて PROGRESS.md に書いて進める。
   仮の前提では仕様が決まらない点だけ、最後にまとめて質問する
4. SPEC.md の要点を 10 行以内で報告し、確認を待つ
```

SPEC.md を確認したら、次からは `/milestone` で 1 つずつ進める。
