# 例 2：Three.js のブラウザ映像（制作）

## 元の依頼
> Three.js で、雷に乗って雲から地面へ落ちるシーンを作って

## ヒアリングでの答え方
- 完成物：「単一の HTML、30 秒、1280x720。MP4 への書き出しも」のように、長さと解像度まで答える
- 制約：「ライブラリは Three.js だけ、CDN から 1 つ」のように、外部への依存を決める

## SPEC.md に足すとよい合格条件
```text
- window.renderAt(t) で、任意の時刻 t の状態を再現できる。乱数はシードを固定する
  （確認：同じ t を 2 回描いて、画像が一致）
- t = 0, 20, 40, 60, 80, 100% の 6 枚を撮り、画像を開いて、主役が画面の中にあることを確かめる
  （確認：Playwright のスクリーンショット）
- コンソールのエラー 0、1280x720 で平均 30fps 以上（確認：計測して記録）
- 30 秒の間、カメラが地形や雲のメッシュにめり込まない（確認：全フレームで距離を検査）
```

## マイルストーンの切り方
M1 箱と線だけで、30 秒のカメラの動きと renderAt(t) を通す → M2 雲と雷の形 → M3 光と色 →
M4 地面と着地 → M5 書き出しと最終の検査

## 補足
- 見た目は、キーフレームの画像を `reviewer` に「初めて見る人」の役で見せる
- 画面の確認に Playwright の MCP を使うなら、`docs/setup-mcp-and-skills.md` の手順で有効にする
