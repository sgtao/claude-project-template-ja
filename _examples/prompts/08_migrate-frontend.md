# 例 8：Vue 2 から Vue 3 への移行（制作・移行）

## 元の依頼
> 管理画面を Vue 3 と Vite に移したい。見た目と動きは変えたくない

## ヒアリングでの答え方
答えの見本：[`answers/migrate-frontend.json`](../answers/migrate-frontend.json)

- 始め方：移行（`migrate`）。移行元と移行先を、版まで書く
- 今の状態：画面の数とテストの件数を書く（同等性の基準の元になる）
- 制約：「移行の途中も main は動く状態に保つ」のように、切り戻しの前提を書く

## SPEC.md に足すとよい合格条件
```text
- 移行の前に、12 画面のスクリーンショットと単体テスト 85 件の結果を基準として保存する（確認：基準のフォルダ）
- 12 画面すべてで、移行の前後のスクリーンショットの差が 0.5% 以下（確認：画像の差分のスクリプト）
- 単体テスト 85 件が移行の後も通る（確認：Vitest）
- 本番のビルドの時間が、移行の前の 50% 以下（確認：3 回の計測の中央値）
- 意図して変えた点は DECISIONS.md に 1 件 1 行で書く（確認：差分の一覧と照合）
```

## 審査の役割
初めて触るユーザーに、移行元の保守担当の観点を足す（同等性の基準から外れた動作を探す）。

## 人の確認点
同等性の基準（どこまで同じなら移行できたとするか）と、main へのマージ。
