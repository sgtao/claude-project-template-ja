# retro：履歴からリポジトリを良くする

## 手順

1. **材料を集める**（記録ファイルを丸ごと読まない）
   - `DECISIONS.md` の「学び」のうち、「反映先」が空の行
   - `python3 _tools/conv.py toc` で前回の振り返り以降の Q&A の題名を見る
   - `python3 _tools/conv.py find "やり直し|違う|ではなく|直して|もう一度"` で、直された場面を探す
   - 気になる Q&A だけ `conv.py show <番号> <Q番号>` で読む
   - `PROGRESS.md` の「方針を変えた記録」と「未検証」
2. **繰り返しを見つける**：同じ種類の指摘や失敗が 2 回以上あるものを挙げる。1 回だけのものは対象にしない。
3. **修正案を作る**：1 つの繰り返しにつき、次のどれか 1 つを選ぶ。上にあるものほど効きが確実。
   1. `_tools/` の検査を足す（機械で確かめられるなら、これを選ぶ）
   2. SPEC.md／BRIEF.md／PLAYBOOK.md の合格条件を足す
   3. スキルの手順を直す
   4. `CLAUDE.md` のルールを足す（1 行で、理由を添える）
   あわせて、使われていないルールや、不要な確認を生んでいる注意書きの**削除**も提案する。
4. **示す**：修正案を表で示す（繰り返しの内容／根拠の記録 `1108-05 Q9`／修正先／修正の文面）。
   5 件まで。AskUserQuestion で、反映するものを選んでもらう。
5. **反映する**：承認されたものだけを反映し、`DECISIONS.md` の該当行の「反映先」を埋め、コミットする。

## やらないこと
- 過去の記録ファイルを書き換えない
- 承認のない修正を `CLAUDE.md` に入れない
- 1 回きりの出来事から、ルールを作らない
